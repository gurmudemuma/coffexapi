## **🎯 Brand Application Details**

### **Background Colors:**
```css
/* Main backgrounds */
bg-yellow-50     /* Light golden background for main areas */
bg-white         /* Card and sidebar backgrounds */
bg-purple-50     /* Sidebar headers and light accents */
bg-purple-900    /* Main headers and navigation bars */

/* Accent backgrounds */
bg-yellow-100    /* Icon backgrounds and highlights */
bg-purple-100    /* Active states and selected items */
```

### **Text Colors:**
```css
/* Primary text */
text-black       /* Main headings and important text */
text-yellow-400  /* Header text on dark backgrounds */

/* Secondary text */
text-purple-600  /* Secondary text and labels */
text-purple-300  /* Muted text on dark backgrounds */
text-purple-500  /* Tertiary text and placeholders */
```

### **Border Colors:**
```css
/* Primary borders */
border-purple-200  /* Card borders and dividers */
border-yellow-200  /* Accent borders and highlights */

/* Interactive borders */
border-purple-400  /* Focus states and active borders */
```

### **Interactive States:**
```css
/* Hover states */
hover:bg-yellow-50     /* Light golden hover for buttons/links */
hover:bg-purple-50     /* Light purple hover for secondary actions */
hover:bg-purple-700    /* Darker purple for primary button hover */

/* Active states */
bg-purple-100          /* Active navigation items */
text-purple-700        /* Active text color */
border-purple-200      /* Active borders */
```
